## 3. معايير إغلاق المرحلة (كلها إلزامية)

1. **توفير النسخة:** مسار **مطلق** لنسخة احتياطية **معتمدة** من المالك + بيان **آلية النسخ** (‏`sqlite3 .backup` / `VACUUM INTO` / نسخ مع إيقاف الخدمة) + الجهة التي اعتمدتها.
2. **تحقق مسبق:** `--verify` على النسخة ⇒ **OK** (سلامة `integrity_check` · صفر انتهاكات مفاتيح أجنبية · تغطية الأسماء كاملة · لا ملفات مرافقة `-wal/-shm/-journal` · ثبات البصمة والحجم والوقت).
3. **الفحص الكامل:** تشغيل الأداة على النسخة مع تسجيل **SHA-256 قبل وبعد** (إلزامي إرفاقه بالتقرير).
4. **تقرير بأرقام حقيقية:** عدد السجلات المفحوصة · عدد مجموعات التعارض والحسابات المتأثرة · تصنيف كل تعارض وفق قاعدة التطبيع · أثر كل تصنيف على إنشاء الحساب وتسجيل الدخول.
5. **قرار المالك** في سياسة معالجة التعارضات (لا حذف · لا إعادة تسمية آلية · لا تعطيل دون إذن).
6. **موافقة صريحة منفصلة** قبل أي Migration أو فهرس فريد أو أي تعديل بيانات/مخطط.

## 4. الإجراء الجاهز لحظة وصول النسخة

```bash
# (1) التحقق من السلامة والاكتمال — يجب أن يخرج بـ 0
python SmartSchoolAPI/Tools/find_duplicate_usernames.py "/ABS/PATH/copy-school_system.db" --verify

# (2) الفحص الكامل (يطبع بصمة SHA-256 قبل وبعد)
python SmartSchoolAPI/Tools/find_duplicate_usernames.py "/ABS/PATH/copy-school_system.db"

# (3) نسخة JSON مُخفّاة الأسماء للمشاركة
python SmartSchoolAPI/Tools/find_duplicate_usernames.py "/ABS/PATH/copy-school_system.db" --json --mask
```

**ملاحظات إلزامية عند التنفيذ:**
- يُستبدل `ABS/PATH` بالمسار الفعلي؛ ويُسجَّل المسار كما هو في التقرير النهائي.
- لا يُشغَّل الفحص على ملف الإنتاج نفسه، ولا يُنشأ أي اتصال به، ولا تُنشأ نسخة تلقائياً.
- تُرفق البصمة (`sha256`) كما طبعتها الأداة، مع نتيجة `--verify`.
- النسخة لا تُشارَك مع أي جهة خارجية؛ يكفي ناتج `--json --mask`.
